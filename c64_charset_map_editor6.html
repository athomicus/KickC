C64 Charset Editor (8x8 hires) + Map Editor

0. Projekt (zapis / wczytanie całości)

Zapisuje charset + mapę + obiekty (multi-tile sprite'y) + ustawienia do jednego pliku .json, żeby wczytać go później i kontynuować pracę bez rysowania od nowa.

0b. Import znaków / obiektów z obrazka (PNG/JPG)

Wczytaj obrazek 8x8, 16x16, 32x32 lub 64x64 px. Program pokroi go na kafelki 8x8 i wpisze je do charsetu. Obrazki większe niż 8x8 (16x16 = 4 kafle, 32x32 = 16 kafli, 64x64 = 64 kafle) dodatkowo zapamiętuje jako gotowy "obiekt" (multi-tile sprite) widoczny w panelu obiektów przy mapie (sekcja 3) — wtedy stemplujesz nim mapę jednym kliknięciem, bez ręcznego układania pojedynczych kafli 8x8.
