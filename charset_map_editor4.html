C64 Charset Editor (8x8 hires) + Map Editor

0. Projekt (zapis / wczytanie całości)

Zapisuje charset + mapę + ustawienia do jednego pliku .json, żeby wczytać go później i kontynuować pracę bez rysowania od nowa.

0b. Import znaków z obrazka (PNG/JPG)

Wczytaj obrazek 8x8, 16x16 lub 32x32 px. Program automatycznie pokroi go na kafelki 8x8 i wpisze je jako kolejne znaki w wolne miejsca charsetu (16x16 → 4 znaki, 32x32 → 16 znaków). Obrazek jest binaryzowany (czarno-biały) według progu poniżej.

3. Mapa (kafelki wskazują numer znaku)

Kafelki na mapie renderują realny wzór graficzny znaku z charsetu (nie samą cyfrę), żeby łatwiej było wypełniać mapę bez gubienia się, gdzie co się łączy. Mały numer w rogu każdej komórki dalej pokazuje indeks znaku dla orientacji.




Eksport charsetu (KickC array, do wklejenia w gfx.c)

Eksport mapy (KickC array, do wklejenia w gfx.c)

Eksportuje mapę jako PŁASKĄ tablicę 1D (nie tablicę tablic!), bo KickC nie generuje kodu ASM dla podwójnego indeksowania zmiennymi runtime (map[row][col]). W kodzie C odczytujesz kafelek jako map[(word)row * MAP_WIDTH + col].
